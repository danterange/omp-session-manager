# 安装与使用

## 系统要求

- Windows 10 或 Windows 11，x64。
- 已安装并可使用 OMP；应用需要能够找到 `omp.exe` 才能恢复会话。
- 官方 Release 的 installer 和 portable ZIP 均为 self-contained `win-x64` 构建，不需要单独安装 .NET Desktop Runtime。

## 安装程序

1. 在 Release 页面下载 `OmpSessionManager-Setup-<版本>.exe` 及其同名 `.sha256` 文件。
2. 在下载目录执行：

   ```powershell
   Get-FileHash .\OmpSessionManager-Setup-<版本>.exe -Algorithm SHA256
   ```

3. 将输出的 `Hash` 与 `.sha256` 文件中的哈希值逐字符比较。
4. 一致后运行安装程序。默认安装位置位于当前用户的 LocalAppData 程序目录，不需要管理员权限。
5. 从开始菜单或安装目录启动 `OmpSessionManager.exe`。

安装程序暂未签名。Windows 可能显示来源提示；不要从非 Release 页、转存站或聊天附件安装。

## 便携版

下载 `OmpSessionManager-<版本>-win-x64-portable.zip` 及同名 `.sha256`，校验后解压到任意可写目录，再运行 `OmpSessionManager.exe`。便携版不会把应用文件写入系统目录，但运行后的本地索引仍保存在默认 LocalAppData 位置，除非使用下面的隔离参数。

## OMP 可执行文件定位顺序

恢复会话时，程序按以下顺序查找 `omp.exe`：

1. `--omp-executable <路径>` 显式指定的文件；
2. `%LOCALAPPDATA%\omp\omp.exe`；
3. 当前进程的 `PATH` 环境变量中的 `omp.exe`。

例如：

```powershell
.\OmpSessionManager.exe --omp-executable "D:\Tools\omp\omp.exe"
```

指定路径不存在时程序会显示失败提示，不会尝试向会话窗口注入文本。

## 首次使用

1. 启动应用，等待状态栏完成首次扫描。
2. 主列表显示会话标题、内容简介、工作目录、最近活动时间与状态。
3. 选中一项后，下方详情区可复制 Session ID、工作目录、原始文件路径与摘要。
4. 使用“恢复对话”启动 OMP 原生恢复命令。

默认扫描目录为 `%USERPROFILE%\.omp\agent\sessions`。原始 JSONL 文件不会被应用删除、改写或上传。

## 搜索与标签

- 在“搜索标题和简介”输入一个或多个关键词后按 Enter 或点击“搜索”。
- 多个关键词以空白分隔，全部关键词都必须命中标题或摘要中的至少一个字段。
- `*关键词*` 与 `关键词` 都按包含匹配处理。
- “移除记录”只隐藏管理器索引中的条目；勾选“显示已移除”后可恢复该记录。
- “标记未完成”和“取消未完成”会保存在本地索引。
- “标记打开窗口”仅依据当前用户可见命令行窗口标题进行最佳努力匹配；标题被终端宿主修改、重复或不唯一时，应用不会猜测。
- “恢复未完成”会跳过已移除或原始文件已不存在的条目，并在启动前显示确认。

## 隔离演示与 UI 验收

不要用真实会话数据生成截图。仓库包含虚构样例，可从项目根运行：

```powershell
pwsh -NoLogo -NoProfile -File .\scripts\Start-Demo.ps1
```

该脚本传入以下启动参数：

```text
--agent-directory <虚构样例目录>
--index-file <临时索引文件>
--disable-window-scan
--disable-auto-refresh
--redact-file-path
```

这会避免扫描真实 OMP profile、读取真实命令行窗口或写入默认索引。关闭演示窗口后，脚本会删除临时索引目录。

## 卸载与数据保留

通过 Windows“已安装的应用”卸载，或运行安装目录的卸载程序。卸载应用不会删除 OMP 原始会话，也不会自动删除本地索引。如需删除管理器索引，请先退出应用，再删除：

```text
%LOCALAPPDATA%\OmpSessionManager\sessions.json
```

删除该索引只会清除本工具的“移除”和“未完成”标签等本地状态，不能删除 OMP 原始会话。

## 常见问题

### 找不到 `omp.exe`

使用 `--omp-executable` 指定实际路径，或把该目录加入当前启动环境的 `PATH` 后重试。

### 扫描结果为空

确认当前 Windows 用户存在 OMP 会话目录。应用只扫描当前用户默认 OMP profile；多 profile 或非默认数据根可通过 `--agent-directory` 用于诊断或隔离场景。

### 窗口状态不准确

窗口识别是辅助信息，不是 OMP 官方会话 API。可以手动标记“未完成”，再用筛选和批量恢复继续工作。
