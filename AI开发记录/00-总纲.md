# 项目总纲

## 当前范围与验收

- 目标：将 OMP Session Manager 准备为可公开、可安装和可复用发布的 Windows 项目。
- 本阶段交付：脱敏源码与历史、双语 README、中文细节文档、虚构数据截图、测试覆盖、self-contained 发布物、Inno Setup installer、SHA-256 与 GitHub Release。
- 平台：Windows x64、.NET 9 WinForms。
- 必要验收：发布候选及可达历史不含已识别敏感信息；构建/测试/格式检查通过；安装程序和便携版可生成并校验；远端仓库公开且 Release 资产完整。

## 授权与约束摘要

- 已授权：清理敏感个人信息、重建公开历史、推送、切换仓库为 public、构建安装包、创建 GitHub Release。
- 未授权：伪造代码签名、选择开源许可证、上传真实会话数据或截图、绕过账户/权限限制。
- 版本以 `Directory.Build.props` 为唯一来源；公开前必须执行历史隐私扫描。

## 当前状态

- 状态：进行中。
- 已完成：项目结构与远端权限预检；当前代码和文档敏感信息审计；发布前 C# 修复、单一版本来源、测试分类、演示启动参数、发布脚本与文档基础设施。
- 待完成：生成并核验脱敏截图、执行完整质量门禁和 installer 验证、重建无个人身份的 Git 历史、私有远端复核、切换 public、发布 `v1.0.0`、验证 Release 资产。
