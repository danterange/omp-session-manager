# 架构说明

## 组件

| 组件 | 职责 |
| --- | --- |
| `AppLaunchOptions` | 解析隔离数据目录、索引文件、OMP 可执行文件与演示开关。 |
| `Form1` | WinForms 主界面、筛选、操作状态与刷新生命周期。 |
| `OmpSessionScanner` | 以共享读取方式扫描 JSONL，提取可恢复会话的最小元数据。 |
| `SessionStore` | 在 LocalAppData 中原子保存索引与用户标签，并兼容可编辑 JSON 的 null 字段。 |
| `SessionSearch` | 对标题和摘要执行多关键词 AND 搜索。 |
| `OmpWindowScanner` | 枚举当前用户桌面上的命令行顶层窗口。 |
| `OmpWindowMatcher` | 用完整会话标题和唯一活动工作目录名进行保守匹配。 |
| `OmpLauncher` | 按显式路径、默认目录和 `PATH` 查找 `omp.exe`，用 `--resume=<id>` 启动恢复。 |

## 数据流

```text
OMP JSONL
   │  共享读取、字段类型校验
   ▼
OmpSessionScanner ──► SessionStore.MergeDiscovered ──► 本地 JSON 索引
                                 │
当前桌面窗口 ─► OmpWindowScanner ─► OmpWindowMatcher ─► 窗口打开状态
                                 │
                                 ▼
                              Form1 列表 / 搜索 / 标签
                                 │
                                 ▼
                       OmpLauncher: omp.exe --resume=<id>
```

## 可靠性约束

- JSONL 会话可能正在被 OMP 追加写入，因此扫描器使用 `FileShare.ReadWrite`，并跳过不完整或类型不匹配的记录。
- 刷新期间会禁用会写入索引和启动恢复的动作，避免后台旧快照覆盖用户刚保存的标签。
- 窗口关闭时会取消刷新续体对 UI 的更新；已开始的文件读取允许自行结束，但不会再访问已释放控件。
- 目录名回退只在候选会话唯一且仍被写入时使用；不确定时宁可不匹配。

## 演示与测试边界

启动参数只用于隔离测试、演示和诊断。未指定参数时，程序继续使用默认 OMP profile 与本地索引。参见 [安装与使用](安装与使用.md) 和 [测试与质量](测试与质量.md)。
