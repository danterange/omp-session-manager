# 隐私与数据处理

## 数据边界

OMP Session Manager 是本地桌面工具。当前源码中没有把会话数据发送到网络的功能，也没有内置遥测、云同步或账户登录功能。它读取本机文件与当前用户桌面窗口，只为呈现会话和执行本地恢复命令。

程序会读取 OMP JSONL 会话中的以下信息：

- Session ID；
- 标题；
- 工作目录；
- 创建和最近活动时间；
- 首条用户消息的文本摘要，最多 180 个字符；
- 当前文件是否仍被写入的状态。

为保存“已移除”和“未完成”标签，程序会在下列本地位置维护 JSON 索引：

```text
%LOCALAPPDATA%\OmpSessionManager\sessions.json
```

索引包含上述会话元数据及标签。它不是加密存储，也不会复制完整对话。因此，索引、程序界面和截图都可能包含你不希望公开的工作目录、标题或摘要。

## 不会做什么

- 不删除或重写 OMP 原始 JSONL 会话；
- 不上传会话、索引、窗口标题或工作目录；
- 不自动打开浏览器、创建账号或发送消息；
- 不自动下载、安装或执行应用更新。

OMP 本身和终端宿主的行为不属于本项目控制范围；本说明只覆盖本仓库中的应用代码。

## 截图、Issue 和日志

在提交 Issue、讨论、截图、录屏或发布前，请删除或遮挡：

- 用户名、邮箱、机器名和绝对用户目录；
- Session ID、标题、摘要、工作目录和原始 JSONL 路径；
- 令牌、密码、私钥、证书和环境变量；
- Windows 任务栏、通知、浏览器标签和其他不相关应用内容。

仓库中的 `samples/demo-agent/` 和 README 截图只允许使用完全虚构的数据。`scripts/Start-Demo.ps1` 会将演示索引置于临时目录，并关闭窗口扫描与自动刷新。

## 公开发布前检查

`scripts/Test-PublicReleaseContent.ps1` 对发布候选文件执行高置信度密钥、绝对用户目录与邮箱模式扫描。传入 `-IncludeGitHistory` 时，它还检查可达 Git 历史中的提交身份、提交信息和文件内容。该脚本不能证明不存在所有类型的敏感数据，因此发布者仍须人工审查：

```powershell
pwsh -NoLogo -NoProfile -File .\scripts\Test-PublicReleaseContent.ps1 -IncludeGitHistory
git diff --check
git status --short
```

任何已进入可达 Git 历史的敏感信息都需要先重写历史、移除旧 ref，再推送清理后的历史；只在新提交中删除文件并不足以清除旧 blob。

## 本地数据清理

如需清空本工具的索引，关闭应用后删除 `%LOCALAPPDATA%\OmpSessionManager\sessions.json`。这不会影响 OMP 原始会话。删除或分享任何数据前，请确认路径和范围，避免误删其他用户文件。
