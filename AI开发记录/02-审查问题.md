# 审查问题

## 已处理

| 级别 | 发现 | 处理 | 验证 |
| --- | --- | --- | --- |
| 必须修复 | 合法但字段类型异常的 JSONL 可能抛出异常 | 为 JSON 对象、字符串字段和数组元素增加类型校验与窄范围兜底 | 新增异常字段回归测试 |
| 必须修复 | 刷新旧快照可能覆盖用户刚保存的标签 | 刷新期间禁用会写索引或恢复会话的动作 | 独立 C# 审查通过 |
| 必须修复 | 关闭窗体后刷新续体可能访问已释放控件 | 关闭标志、CancellationToken 与 disposed guard | 独立 C# 审查通过 |
| 必须修复 | 可编辑索引中的 null 字段可能破坏搜索或路径匹配 | 读取时归一化记录，搜索和路径解析额外防御 | 新增 null/非法路径测试 |
| 必须修复 | OMP 路径仅支持一个固定位置 | 支持显式路径、默认目录和 `PATH`，并增加测试 | 单元测试 |
| 必须修复 | 旧文档、测试夹具与历史包含环境和身份痕迹 | 以虚构样例替换；计划重建可达历史 | 发布前扫描 |

## 当前发布风险

- 安装程序未签名：这是已知限制，README 和 Release notes 必须如实提示。
- 当前未附开源许可证：公开可见不等同于开源授权，不能自行选择许可证。
- UI smoke 仅验证构造与 automation name；真实交互需用虚构数据进行手工验收。
- 多个应用实例同时写同一索引的跨进程协调尚未实现，属于后续增强，不作为当前单实例发布阻塞项。

## 复审结论

本阶段独立 C# 审查已覆盖 JSON、持久化、WinForms 生命周期、OMP 定位、版本来源与测试；在当前源码变更范围内未发现新的确定性 Release blocker。最终结论仍依赖完整质量门禁、安装包和远端发布验证。
