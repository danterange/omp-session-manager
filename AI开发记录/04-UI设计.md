# UI 设计

## 主路径

```text
启动 → 扫描 → 查看列表 → 搜索/筛选 → 标记状态 → 恢复会话
```

主窗体由两行工具栏、会话表格、详情区和状态栏构成：

- 第一行：刷新、单项恢复、移除/恢复记录、显示已移除、只显示未完成。
- 第二行：多关键词搜索、标记打开窗口、手动未完成标签、批量恢复未完成会话。
- 表格：标题、摘要、工作目录、最近活动和状态。
- 详情：可复制的 Session ID、目录、原始文件和摘要。

## 安全与状态

- 刷新期间禁用会改变索引或启动恢复的按钮，防止陈旧扫描结果覆盖用户动作。
- 扫描失败时保留上一次可用列表，并显示不含本地路径的错误说明。
- 标题/目录匹配不确定时不自动猜测；用户可以手动标记。
- UI automation 使用稳定的 English `Name` 与中文 `AccessibleName`，避免测试依赖可见翻译文本。
