# 开发规划

## 发布任务清单

| 编号 | 事项 | 验收方式 | 状态 |
| --- | --- | --- | --- |
| PUB-01 | 清理当前文件中的个人信息和环境痕迹 | 发布候选内容扫描、人工审查 | 进行中 |
| PUB-02 | 清理可达 Git 历史身份和旧内容 | 重建根提交、历史扫描 | 待执行 |
| PUB-03 | 补齐双语 README 与中文细节文档 | 链接、命令和截图均有效 | 进行中 |
| PUB-04 | 提供可安装发布物 | self-contained publish、installer、ZIP、hash | 进行中 |
| PUB-05 | 增强质量门禁 | Unit、Integration、UI smoke、格式与隐私扫描 | 进行中 |
| PUB-06 | GitHub public 与 Release | 远端可见性、tag、四个资产和回读验证 | 待执行 |

## 执行顺序

1. 修改源码、测试和文档，消除当前树中的公开风险。
2. 用虚构 JSONL 和临时索引运行演示，生成经人工核验的 PNG。
3. 运行完整质量门禁、installer 构建、发布目录扫描与本机安装验证。
4. 创建无个人身份的 orphan 根提交，并 force push 到仍为 private 的远端。
5. 对远端默认分支重新执行历史内容和身份扫描。
6. 将仓库切换为 public。
7. 创建版本 tag、GitHub Release 和校验资产，回读资产列表与哈希。

## 范围外

- 内置 auto-update 网络客户端、自动下载器和静默安装器。
- 代码签名证书、Publisher 身份或组织级安全策略。
- 未经权利人决定的开源许可证选择。
- 真实 OMP profile、真实会话或生产数据的自动化恢复测试。
