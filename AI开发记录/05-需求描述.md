# 需求描述

## 产品目标

为 Windows 上使用 OMP 的用户提供一个本地会话管理界面：快速发现历史会话、按标题和摘要搜索、保留待办状态，并使用 OMP 原生 resume 参数恢复工作。

## 本次发布需求

- 将项目发布为 public GitHub 仓库，同时移除当前树和可达历史中的敏感个人信息。
- 提供中英双语 README、中文细节 Markdown 文档、完全虚构演示数据生成的界面截图与使用说明。
- 构建可安装的 Windows Release：installer、portable ZIP 和 SHA-256。
- 建立可复用流程：代码审查、Unit/Integration/UI 测试、隐私扫描、版本升级、本地 commit、远程 push、GitHub Release 与资产验证。
- 在根目录创建并维护 `AGENTS.md`，引用 `docs/` 中的发布、测试、隐私和自动更新文档。

## 不应声称的能力

- 不声称已具备内置 auto-update、云同步、遥测、代码签名或开源许可证。
- 不将窗口标题匹配描述为官方精确会话关联。
- 不将“移除记录”描述为删除 OMP 原始会话。
