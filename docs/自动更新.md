# 自动更新说明

## 当前状态

当前版本**没有内置自动更新器**。应用不会主动访问 GitHub、下载新版本、替换正在运行的文件或静默安装更新。任何文档、截图、Release notes 或自动化代理都不得将“发布流程自动化”描述为“程序自动更新”。

## 手动更新

1. 在 Release 页面下载更高版本的 installer 或 portable ZIP，并校验 SHA-256。
2. 关闭 OMP Session Manager。
3. 安装版：运行新安装程序并按提示覆盖当前用户安装。便携版：解压到新目录或替换现有文件。
4. 重新启动应用。默认本地索引不随应用升级删除，原始 OMP 会话也不受影响。

如升级后出现异常，可先保留 `%LOCALAPPDATA%\OmpSessionManager\sessions.json` 的副本，再按 [隐私与数据处理](隐私与数据处理.md) 的范围说明决定是否清理索引。

## 未来实现的安全约束

若未来引入 auto-update，至少应满足：

- 仅从明确、受控的 Release 来源读取版本清单；
- 下载前后校验 HTTPS、版本号、SHA-256 和发布资产名称；
- 如引入签名，验证代码签名或受信任的公钥签名；
- 让用户明确选择下载、安装、重启与回滚，不在 Office/OMP 会话运行期间强制覆盖；
- 在替换前保留可恢复的旧版本，并记录无敏感信息的失败原因；
- 使用独立 updater 进程处理文件占用，不能由正在被替换的主 EXE 自行覆盖；
- 为网络失败、断电、磁盘空间不足、签名失败和回滚路径提供测试。

这是一份设计约束，不是当前程序已实现的功能。
